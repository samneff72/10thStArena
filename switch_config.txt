! Reference configuration for the Catalyst 3560-CX (12-port, IP Base): what a working field
! switch looks like, recorded for comparison and for a switch you would rather set up by
! hand.
!
! Setting one up does not need this file. docs/switch-bootstrap.py brings a factory switch
! to the point bioarena can reach it -- address, passwords, boot image -- and bioarena
! pushes the VLANs, ports, portfast and routing itself on its first configuration. Telnet
! password and enable secret must match each other; the same value goes in Switch Password
! under Arena -> Settings.
!
! Port map -- see docs/sites/richmond.md:
!
!   Gi0/1-6    driver stations R1, R2, R3, B1, B2, B3   access vlan 10/20/30/40/50/60
!   Gi0/7      field controller Pi (FMS, 10.0.100.5)    trunk, native vlan 1
!   Gi0/8      field access point                       trunk, native vlan 1
!   Gi0/9      Art-Net node (10.0.100.100)              access vlan 1
!   Gi0/10-12  spare, for troubleshooting               access vlan 1
!
! Management is VLAN 1, which is what the hardware runs: docs/switch-bootstrap.py sets the
! address on interface Vlan1, and bioarena's baseline adds the access point's subnet there
! as a secondary. A dedicated management VLAN would be tidier, but nothing here uses one
! and a file that describes a field nobody has built is worse than an untidy one.
!
! Gi0/1-6 are not arbitrary. network/switch.go hardcodes them as dsPortInterfaces in
! station order and shuts and reopens each one around a VLAN change, which is what makes a
! driver station laptop re-request an address on its new subnet. Move a station to another
! port and it keeps the previous match's address.
!
! Everything under "interface Vlan10" through "interface Vlan60", and every dhcp pool named
! dhcpNN or stagingNN, is rewritten by bioarena on each match load. The addresses below are
! only placeholders so the SVIs exist before the first match.
!
version 15.2
no service pad
service timestamps debug datetime msec
service timestamps log datetime msec
no service password-encryption
!
hostname bioSwitch
!
boot-start-marker
boot system flash:c3560cx-universalk9-mz.152-7.E/c3560cx-universalk9-mz.152-7.E.bin
boot-end-marker
!
enable secret 5 $1$kKSW$fCMwnMdYvXui1TulfyYHN/
!
no aaa new-model
ip routing
!
! Field network. .1-.125 is excluded so the statically addressed field devices -- the Pi at
! .5, this switch at .3, the access point at .2, the Art-Net node at .100 -- can never
! collide with a lease. The wide exclusion is upstream's and is kept as-is.
ip dhcp excluded-address 10.0.100.1 10.0.100.125
ip dhcp excluded-address 10.0.100.200 10.0.100.225
!
ip dhcp pool dhcppool
 network 10.0.100.0 255.255.255.0

!
ip route 0.0.0.0 0.0.0.0 10.0.100.1
ip route 10.0.0.0 255.0.0.0 Null0
!
lldp run

!

! Access point. The VH-113 tags each team's SSID onto that team's VLAN, so all six have to
! reach it -- an access port here leaves every robot associated to WiFi and unable to reach
! anything. No "switchport trunk encapsulation dot1q": the 3560-CX is 802.1Q-only and does
! not have the command.
interface GigabitEthernet0/7
 description Field controller Pi (FMS)
 switchport trunk native vlan 1
 switchport trunk allowed vlan 1,10,20,30,40,50,60
 switchport mode trunk
!
interface GigabitEthernet0/8
 description Field access point
 switchport trunk native vlan 1
 switchport trunk allowed vlan 1,10,20,30,40,50,60
 switchport mode trunk
!

!
! Management, and the access point's backup subnet as a secondary. The VH-113 lives at
! 10.0.100.2 on this subnet, which is what bioarena talks to -- but it also answers on
! 192.168.69.1, and that is where it turns up after a reset. Carrying that subnet here keeps
! the fallback reachable from the field; the Pi holds 192.168.69.5 on the same VLAN.
interface Vlan1
 ip address 10.0.100.3 255.255.255.0
 ip address 192.168.69.2 255.255.255.0 secondary
!
ip classless
ip http server
ip http secure-server
!
! Applied inbound on the team VLANs: a driver station may reach the FMS and nothing else.
!
! The 0.255.255.0 wildcard on the second icmp line is discontiguous and deliberate. It
! matches the first and last octets only -- 10.*.*.4 -- which is every team subnet's
! gateway, switchTeamGatewayAddress in network/switch.go. One ACE covers all six VLANs
! whatever team numbers are loaded, so a driver station can always ping its own gateway.
! It is not a typo for 0.0.0.255; do not "correct" it.
ip access-list extended DS-FMS
 permit udp any eq 1145 10.0.100.0 0.0.0.255 eq 1160
 permit tcp any 10.0.100.0 0.0.0.255 eq 1750
 permit icmp any 10.0.100.0 0.0.0.255
 permit icmp any 10.0.0.4 0.255.255.0
 permit udp any any eq bootpc
 permit udp any any eq bootps
!
snmp-server community 1234Five RO
!
line con 0
 exec-timeout 0 0
line vty 0 4
 password 1234Five
 login
line vty 5 15
 password 1234Five
 login
!
end
