Networking

Enable this setting if you have a Vivid-Hosting VH-113 access point and Cisco Catalyst 3560-CX switch available, for isolating each team to its own SSID and VLAN.

Configures the AP and switch on every match load. Turn it off to run matches without touching network hardware — useful on a bench, or if the switch fails mid-session. Saved here and kept across restarts.
Must match the switch's enable password as well as the VTY line password — bioarena sends this one value for both.
Handed to driver stations and robots in each team's DHCP lease. Leave blank unless the field has an upstream resolver: a DNS server the team subnet cannot reach makes every lookup wait for a timeout rather than fail immediately.
E-Stop Panels
Driver Station

When enabled, the Driver Station software will prompt teams to allow Bioarena to connect rather than automatically connecting, and will preserve the ability to use the spacebar for robot disablement. Consider enabling this setting when physical E-Stop buttons are not present.

DMX Hub LEDs

Defaults match the standard arena: upstream's full-field layout of eight fixtures per alliance across four sides of each goal, running every lighting sequence unmodified. Override below for a practice field with simpler fixtures.

Leave blank to disable LED output.
Same pixels and layout, a different packet: Art-Net on UDP 6454 rather than E1.31 sACN on 5568. Tick it for a gateway that speaks only Art-Net. The universe number below is sent unchanged either way, so the gateway stays on universe 1 whichever protocol it is set to.
Fill, sweep and rainbow sequences are meaningless on a fixture with one pixel; they would show whichever colour that pixel happened to be mid-animation. Solid replaces them with the alliance colour.
One fixture per alliance Hub instead of eight. Unchecked keeps the standard arena layout.

Fixtures must sit at least 24 channels apart in a universe. The renderer always writes a 24-channel block per fixture; a single-pixel unit reads the first three and ignores the rest, but a second fixture placed inside that block would be overwritten. Invalid spacing is rejected on save.
